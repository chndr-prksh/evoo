Install

Two ways to install.

Evoo is free and open source, so it isn't signed with a paid Apple certificate. That means macOS asks you to confirm it once. The one-line install skips that step entirely.

Recommended

Option A · One line in Terminal

Open Terminal (press ⌘ Space, type “Terminal”), paste this, and press Return. It downloads the latest version, verifies it, installs it to Applications and opens it — no warning.

$ curl -fsSL https://raw.githubusercontent.com/chndr-prksh/evoo/main/install.sh | bash

Want to see what it runs first? Read install.sh — it's short.

Option B · Download the app

  1. Download Evoo.zip, unzip it, and drag Evoo into Applications.
  2. Open Evoo. macOS says it “could not verify Evoo is free of malware”. Click Done (not Move to Trash).
  3. Open System Settings › Privacy & Security, scroll down, and click Open Anyway next to “Evoo was blocked”.
Security
“Evoo” was blocked to protect your Mac.Open Anyway
  1. Enter your Mac password and click Open Anyway again. You only do this once.

Or clear the warning in Terminal instead:

$ xattr -dr com.apple.quarantine /Applications/Evoo.app
ℹ️
Why the warning? Apple shows it for any app not signed with a $99/year developer certificate — it isn't a malware finding. Evoo's full source is public on GitHub, every release is built there automatically, and it never uploads your audio or text.

Then, one-time setup (about a minute)

Evoo's welcome tour walks you through this and ticks each step off as you go — then one click on Set up & continue downloads the local AI model and turns on the recommended settings. No trip to Settings needed.

Privacy

Your voice never leaves your Mac.

Speech recognition, corrections and the optional AI all run on your Mac's own chip.

  • No account, no API keys. Nothing to sign up for.
  • Works offline. Turn off Wi-Fi and keep dictating.
  • Nothing uploaded. Audio is discarded after each dictation.
  • Open source (Apache-2.0). Every line is public — and every model is open-weight.

FAQ

Questions

Is Evoo really free?

Yes. No subscription, no trial, no account. It's open source under Apache-2.0, and every model it uses is free and open-weight.

Is it safe? macOS says it “could not verify” it.

That message appears for every app not signed with a paid Apple developer certificate — it doesn't mean anything was detected. You can read all of Evoo's code on GitHub, releases are built there automatically, and the one-line install checks the download's checksum. Evoo only goes online to download its models and check GitHub for updates.

Does the AI polish understand context, or just grammar?

Both. Besides fillers, self-corrections and grammar, it fixes words the speech model misheard when the meaning makes it obvious — “Jack and Gill went up the hell” becomes “Jack and Jill went up the hill”, “I need to by milk” becomes “I need to buy milk”. On Macs with 16 GB or more it also reads the sentences you said just before and the text already in the box, so it knows the topic. It never changes a word that already makes sense, and it all runs on your Mac.

Which Macs does it work on?

Apple Silicon Macs (M1 or newer) with macOS 14 Sonoma or later. 8 GB of memory is enough for dictation; 16 GB gives the optional local AI (rewrite, reply, Class Notes) more room.

Which apps does it work in?

Anywhere you can type: Chrome, Safari, Slack, WhatsApp, Gmail, Notion, Notes, Word, VS Code, Cursor, Terminal and more. It formats for each — Markdown in editors, plain bullets in chat, and never a line break in Terminal.

I use Wispr Flow or Apple Dictation — can I keep them?

Yes, but don't run two fn-based dictation apps at once; both will react to the key. Set Keyboard › Press 🌐 key to › Do Nothing so Apple's dictation doesn't pop up too.

Can I move the floating pill?

Yes. Drag it anywhere along the bottom of the screen, or up the left or right side, where it stands upright. Or pick a spot in Settings › Pill position. It remembers where you left it.

My first word sometimes gets cut off. Can I fix that?

Turn on Settings › Keep the microphone ready. The mic stays on between dictations and Evoo keeps only the last 0.3 seconds in memory, so recording starts the instant you press fn and even includes the moment just before. macOS shows its orange microphone dot while it's on; nothing is transcribed or saved until you press fn.

Which languages?

English, plus a Hinglish add-on (beta): download it in Settings and switch languages from the pill. It writes Hindi–English the way people type it in chat — "kal meeting hai, please confirm kar dena" — using its own speech model, so English isn't affected.

How do updates work?

Evoo checks GitHub every few hours. When a new version is out, a dot appears by its menu bar icon — choose Install Update and it relaunches, keeping your settings and permissions.
